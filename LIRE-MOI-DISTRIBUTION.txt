HÉPHAÏSTOS BETA 1.1 — version Windows x64

Lancement
---------
1. Décompressez entièrement le fichier ZIP dans un dossier.
2. Ouvrez ce dossier.
3. Double-cliquez sur Hephaistos.exe.

Aucune installation du runtime .NET et aucune utilisation de PowerShell ne sont nécessaires pour lancer Héphaïstos.

Première configuration de l’IA locale
-------------------------------------
Héphaïstos utilise Ollama et deux modèles locaux :
- qwen3:8b
- qwen3-embedding:0.6b

Si le moteur ou les modèles manquent, Héphaïstos ouvre automatiquement une fenêtre « IA locale ».
Le bouton « Configurer maintenant » :
- télécharge l’installateur officiel Ollama si nécessaire ;
- ouvre cet installateur Windows ;
- puis télécharge les modèles directement depuis Ollama.

Le téléchargement des deux modèles représente environ 5,8 Go. Une connexion Internet est donc nécessaire lors de la première configuration.

Vie privée
----------
Les analyses et les requêtes d’Héphaïstos sont ensuite envoyées au moteur Ollama qui tourne localement sur l’ordinateur (localhost). Les documents ne sont pas envoyés à un service d’IA distant par Héphaïstos.

Configuration ultérieure
-------------------------
Le bouton « IA locale » en haut à droite de l’application permet de vérifier ou relancer la configuration à tout moment.
